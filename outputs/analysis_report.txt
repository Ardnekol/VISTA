CODE PIPELINE

STEP 1 — DATASET GENERATION
data_generation.py
  → Dataset/profile_description_1to10.json   (95 value profiles)
  → Dataset/scenarios_batch1.json            (10 scenarios)
  → Dataset/modifiers_batch1.json            (80 modifiers)

         ↓

STEP 2 — RULE-BASED DECISIONS (Baseline)
value_decision_analysis.py --profiles Dataset/profile_description_*.json
  → outputs/decision_analysis_*.csv          (dot-product scoring)

         ↓

STEP 3 — LLM DECISIONS
llm_decision_analysis.py --profiles Dataset/profile_description_*.json --suffix llama
  → outputs/llm_decision_analysis_*_llama.csv

llm_decision_analysis.py --profiles Dataset/profile_description_*.json --suffix gemma4
  → outputs/llm_decision_analysis_*_gemma4.csv

         ↓

STEP 4 — MERGE & ANALYZE
merge_and_analyze.py
  → outputs/master_llm_decisions.csv         (8,550 rows)
  → outputs/analysis_report.txt             (flip rates, patterns)
  → outputs/analysis_summary.json           (machine-readable stats)

────────────────────────────────────────────────────────────
EXPERIMENT DESIGN
────────────────────────────────────────────────────────────

  Value Profiles (95 people)
       x  Scenarios (10 situations)
       x  Conditions (9 = 1 baseline + 8 modifiers)
       =  8,550 decision points

  Step 1: DOT-PRODUCT (rule-based)
    score_A0 = sum of profile weights for A0-aligned values
    score_A1 = sum of profile weights for A1-aligned values
    decision = argmax(score_A0, score_A1)

  Step 2: LLM (semantic reasoning)
    Prompt   = profile description + scenario + modifier
    LLM roleplays as the person → outputs A0 or A1 + reasoning

  Step 3: Compare
    - Did the modifier flip the decision?
    - Do LLM and dot-product agree?
    - Which modifier axis flips most?
    - Does profile strength resist modifiers?
